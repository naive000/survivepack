# 核實紀錄：tw-welfare-rent-subsidy

進 `book/`：2026-10-01。

## 自行開啟核對（2026-10-01）

- 內政部不動產資訊平台（`pip.moi.gov.tw/Publicize/Info/B1020`）：用 BrowserOS 讀「申請條件」子頁與主頁的金額表、加碼表；資格（成年、有戶籍、無自有房屋、所得低於最低生活費 3 倍、婚育家庭 3.5 倍）、表 2 各縣市所得上限、每月補貼上限（臺北市 8,000／5,000／3,000 等）都逐項對照。頁面沒有日期。
- 國土管理署公告（`nlma.gov.tw/ch/legislation/law&regu/7243`，2025-09-16）：用 BrowserOS 讀「受理申請期間 115-01-01 至 115-12-31」「以實際租金金額核計，每戶每月最高補貼」「同一家庭一件申請，七日內擇一」「補貼期間未租賃不撥款」。
- 《住宅法》第 9、10 條：官方 Open API 逐條比對（整編日 2026-09-18，最近修正 2026-03-04）：「同一年度僅得擇一辦理」「承租住宅租金補貼以無自有住宅之家庭為限」。
- 公告頁（BrowserOS 再讀）另確認：「租賃契約之出租人或租賃房屋所有權人不得為承租人之家庭成員或直系親屬」；公告的所得規定只寫三倍。
