# 核實紀錄：tw-rent-prenotation-registration

進 `book/`：2026-11-09（階段 3 第一批，草稿 docs/new-entries/2026-11-09-4.md）。以下為草稿「核實紀錄」原文，小標題降級，內容未改；草稿的「建議放置」「格式自查」等舊說明隨之保留，以本檔末段為準。

- 核實日期：2026-11-09。母專案原文只用來理解題意，未複製。
- 母專案編號：15-14「买房签约前查清有没有查封和抵押，签约后去不动产登记机构办预告登记」。差異：母專案依民法典第221條與不動產登記暫行條例，買方可單方申請（期房開發商不配合時），預告登記有90日失效期；台灣土地法第79條之1要求「請求權人檢附登記名義人之同意書」，買方不能單方申請，本次查到的條文與地政事務所公告都沒有90日失效的規定，故台灣版不寫失效期。母專案「簽約前查封抵押」那半已有 `tw-rent-title-search`（任何人可申請第二類謄本）；本條只寫預告登記，且與 `tw-rent-disclosure-statement-review`（說明書）題材不同、不混。實際重疊的現有條目是 `tw-rent-title-search`，已在說人話與備註指向。
- 自行開啟核對（瀏覽器 browserclaw，皆 2026-11-09 開啟）：
  1. https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=D0060001&flno=79-1 與 LawAll：第79條之1「聲請保全左列請求權之預告登記，應由請求權人檢附登記名義人之同意書為之：一、關於土地權利移轉或使其消滅之請求權。二、土地權利內容或次序變更之請求權。三、附條件或期限之請求權。前項預告登記未塗銷前，登記名義人就其土地所為之處分，對於所登記之請求權有妨礙者無效。預告登記，對於因徵收、法院判決或強制執行而為新登記，無排除之效力。」土地法歷史頁：修正日期 113-08-07（只修正第14條），無未施行條文。
  2. https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=D0060003：土地登記規則，歷史頁顯示修正日期 110-07-13（頁面如此顯示，未另行比對其他來源）。第136條「…限制登記，包括預告登記、查封、假扣押、假處分或破產登記，及其他依法律所為禁止處分之登記。」第137條「申請預告登記，除提出第三十四條各款規定之文件外，應提出登記名義人同意書。前項登記名義人除符合第四十一條第二款、第四款至第八款、第十款、第十五款及第十六款規定之情形者外，應親自到場，並依第四十條規定程序辦理。」第146條「預告登記之塗銷，應提出原預告登記請求權人之同意書。…預告登記之請求權為保全土地權利移轉者，請求權人會同申辦權利移轉登記時，於登記申請書備註欄記明併同辦理塗銷預告登記者，免依前二項規定辦理。」第24條之1第二類謄本「…但限制登記、非自然人之姓名及統一編號，不在此限」；第34條、第40條已讀。
  3. 臺中市龍井地政事務所「預告登記」頁（https://ljland.land.taichung.gov.tw/content/?parent_id=10342，更新日期 2025/07/19）：檢附文件「1.土地登記申請書。2.登記清冊。3.登記名義人同意書。4.申請人身分證明文件…5.登記名義人印鑑證明（原因發生日期前一年以後核發）或親自到場提出國民身分證正本由審查人員核對身分並簽名者免附。6.土地、建物所有權狀正本。」處理期限「1個工作天」，規費「免納登記費」。
  4. 嘉義縣大林地政事務所「登記申請案件申辦須知」（https://dalin-land.cyhg.gov.tw/cp.aspx?n=3243，頁尾更新日期 115-11-06）：「14、預告登記 …處理期限(天)：一天 收費標準：免收登記費」；「15、塗銷預告登記 …預告登記請求權人塗銷登記同意書」。
  5. https://epaper.land.moi.gov.tw/Home/SNPayNote：「電子謄本…以張計費，每張二十元」，頁面沒有標示更新日期。
  6. https://glrs.moi.gov.tw/LawContent.aspx?id=GL000442：成屋買賣定型化契約應記載及不得記載事項，修正日期 114-12-19。頁面只有中繼資料，全文是 PDF（FileID=24659，115.4.1 生效版）；該 PDF 用 curl 下載並以 markitdown 轉文字檢索，非瀏覽器開啟。檢索「預告登記」「查封」「限制登記」皆無結果；第五點「原設定抵押權之處理」、第十一點「賣方擔保本買賣標的物權利清楚，並無一物數賣…」原句已讀。進 book/ 前請自己重開 PDF 核對。
  7. https://law.moj.gov.tw/LawClass/LawSingle.aspx?pcode=B0000001&flno=166-1：「契約以負擔不動產物權之移轉、設定或變更之義務為標的者，應由公證人作成公證書。」頁面註記「第 166-1 條條文施行日期，由行政院會同司法院另定之」，未施行；本條沒有當現行規定寫，只在備註說明。

### 2026-11-09 Opus 驗收修正

合併位置：book/rent.md（放在 tw-rent-title-search 之後）。Opus 驗收（唯讀，所有來源自行重開）後套用的修正與使用者決定：

- 使用者決定／規則判定（2026-11-09）：收益維持標 ?（依 CLAUDE.md，金額無官方數字或跨級距就標 ?，不比照 tw-rent-home-purchase-escrow 標「大」）；時間成本標「少」（一次跑地政事務所、處理期限一個工作天）。
- 套用 Opus 3-1（實質錯誤更正）：草稿寫「法律上沒有買方單獨申請的途徑」是錯的。土地登記規則第 27 條：「下列登記由權利人或登記名義人單獨申請之：…八、預告登記或塗銷登記。」預告登記本來就由買方單獨申請，只是要附賣方同意書。過程成本改為「預告登記由買方單獨申請，但要附賣方同意書（土地登記規則第27條第8款、第137條）。賣方不出具同意書，就辦不成；有沒有其他保全方式，請洽律師或地政士。」本檔上方母專案差異欄「買方不能單方申請」一句同樣作廢。Opus 另指出強制執行法第 130 條（命債務人為一定意思表示之判決確定，視為已為意思表示），賣方拒絕時不能說法律上完全沒有途徑，條目因此不寫「沒有途徑」。法源條號與來源補第 27 條。
