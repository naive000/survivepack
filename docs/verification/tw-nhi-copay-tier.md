# 核實紀錄：tw-nhi-copay-tier（小病先去基層診所，沒有轉診單不要直接掛醫學中心）

進 `book/`：2026-10-01。

## 自行開啟核對（2026-10-01）

- 金額與視同轉診：用 BrowserOS 瀏覽器（正常憑證驗證）開健保署官網，路徑 健保服務 → 就醫費用與退費 → 就醫費用項目 → 部分負擔及免部分負擔說明 → 門、急診部分負擔（`https://www.nhi.gov.tw/ch/lp-2737-1.html`），發布 112-07-27，更新 114-04-22。門診基本部分負擔（106 年 4 月 15 日起生效）：醫學中心 170／420、區域醫院 100／240、地區醫院 50／80、診所 50／50；牙醫與中醫各 50 元；身心障礙手冊者按診所 50 元；視同轉診情形；同一療程免收。這解決了草稿的 TODO 1（金額是否現行）。
- 該頁最近更新是 2025-04-22，之後頁面沒有更動基本部分負擔金額。2025-10-28 媒體報導規劃對無轉診單的醫學中心加收 50%：我沒有在該頁與首頁最新消息看到對應公告，**條目沒寫**；若日後上路，本條金額要整條重寫。
- 《全民健康保險法》第43、48條：官方 Open API（整編日 2026-09-18，最近修正 2023-06-28）逐條比對。
- 《全民健康保險轉診實施辦法》第6條（轉診單效期 90 日）與第11條（無特約診所的鄉鎮市區視同轉診）：先前自行在法規資料庫頁面核對（最近修正 2018-04-27）。命令類另有官方 Open API `https://law.moj.gov.tw/api/Ch/Order/json`（2026-10-01 稍晚下載成功，整編日 2026-09-18），第6條（轉診單效期至多九十日）與第11條（視同轉診五款）已逐字比對，與條目相符。
