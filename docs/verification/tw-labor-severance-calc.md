- 條文：全國法規資料庫 Open API（`https://law.moj.gov.tw/api/Ch/Law/json`），整包下載，資料整編日 2026-09-18，逐條比對：勞基法第 2、11、16、17 條（最近修正 2024-07-31）；勞退條例第 11、12 條（2019-05-15）；勞動事件法第 12、16、24、32 條（2023-12-15）；勞資爭議處理法第 11、12、59 條（2021-04-28）。
- 勞動部頁面（WebFetch 讀取，回傳為摘要與原句引用，不是整頁原文）：
  - 新制資遣費與平均工資，頁面更新 2026-06-23：新制「每滿1年發給1/2個月之平均工資…最高以發給6個月平均工資為限」；平均工資定義同勞基法第 2 條第 4 款；簡易算法「以勞工退休前6個月工資總額直接除以6，較為簡易、準確及合理」。這頁講退休，條目據此寫「勞動部頁面說簡易算法是前六個月工資總額直接除以 6」，沒有擴張成資遣專屬規則。
  - 勞資爭議調解制度，頁面更新 2026-09-03：「提供勞資雙方當事人及時、便捷、保密且免費之紛爭處理途徑」。
  - 勞工法律及生活費用扶助，頁面更新 2026-09-03：「申請時每月收入總計不超過新臺幣6萬5,000元，扣除自用住宅外，其資產總額不超過新臺幣300萬元」；「勞工無須負擔任何律師酬金」。

## 從草稿刪掉的內容（原因）

- 勞資爭議調解辦法第 26 條（調解人費用由主管機關支給）：Open API 資料裡找不到這部辦法，無法核對，刪除。
- 民事訴訟法第 77-23、78、466-3 條與「一審、二審律師費可否由敗訴方負擔」：條文沒有明文，結論無法從原文得出，整段不寫，條目寫「本條不寫」。
- 勞委會 83 年函（平均工資除以 6）：未取得函文原件，改引勞動部現行頁面。
- 勞基法第 16 條預告期間：與資遣費計算無關，另可成一條，從法源條號與來源移除。
