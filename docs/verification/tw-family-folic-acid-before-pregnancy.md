## 2026-10-07 收益量級判定

- 依據：De-Regil LM 等，Cochrane Database Syst Rev 2015;(12):CD007950（PMID 26662928）。任何葉酸補充 vs 無介入／安慰劑／不含葉酸的微量營養素，預防神經管缺陷 RR 0.31（95% CI 0.17-0.58），5 項試驗、6708 名新生兒，高品質證據。
- 方式：2026-10-07 以 NCBI E-utilities efetch 重新取得摘要逐字核對，數字相符。只讀摘要，未讀全文。
- 判定：神經管缺陷屬該疾病的重大事件（非篩檢率、檢出率、血壓值等替代終點），相對降幅約 69%（≥20%），標大。
- 疑點：摘要寫明沒有納入評估新生兒死亡的試驗；把「神經管缺陷發生」當作重大事件而非替代終點，是本次判定的解讀，原條目曾寫成「發生率的替代終點」，待使用者確認。
