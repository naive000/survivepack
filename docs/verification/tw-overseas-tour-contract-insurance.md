## 給收錄者：既有條目 tw-overseas-tour-contract-insurance 的修正

背景 agent 回報（Opus 驗收），供合併 agent 一併套用到 `book/`。本檔不改 `book/`。套用前自己重開來源核對一次：旅行業管理規則 https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=K0110002 （看「所有條文」頁與「沿革」頁）。六個條號（第12、36、42、66、68、71條）在現行版都還對得上，不用改條號。

1. 現句：「甲種旅行業保證金最低新臺幣一百五十萬元、乙種新臺幣六十萬元（規則第12條）」。
   新句：「甲種旅行業保證金新臺幣一百五十萬元、乙種六十萬元；具中央主管機關認可觀光公益法人會員資格等條件者，得按十分之一繳納（規則第12條）。」
   來源：旅行業管理規則第12條（第12條是定額，不是最低；第1項第2款第6目可只繳十分之一）。
2. 現句：「履約保證保險最低投保金額，甲種新臺幣三千萬元、乙種新臺幣一千六百萬元（規則第66條）」。
   新句：「…甲種三千萬元、乙種一千六百萬元（第66條第2項）；具認可觀光公益法人會員資格者，最低為甲種一千五百萬元、乙種八百萬元（第66條第3項）。」
   來源：旅行業管理規則第66條第2項、第3項。
3. 現句：「中央主管機關會公告保證金被扣押…」。
   新句：把「會」改成「得」（「交通部觀光署得公告之」）。
   來源：旅行業管理規則第71條。條例第43條這次沒有重開核對。
4. 現句：備註「定型化契約…公告全文，本條沒有在可重抓的官方頁面取得」。
   新句：刪除這句。觀光署法規資訊網有全文，例如第二點「審閱期間不得少於一日」。
   來源：交通部觀光署法規資訊網，國外旅遊定型化契約應記載及不得記載事項 https://law.tad.gov.tw/MOTCTALRS/web_page/MOTCTALRS010300.jsp?LawLevel=%E6%B3%95%E8%A6%8F%E5%91%BD%E4%BB%A4&LawName=%E5%9C%8B%E5%A4%96%E6%97%85%E9%81%8A%E5%AE%9A%E5%9E%8B%E5%8C%96%E5%A5%91%E7%B4%84%E6%87%89%E8%A8%98%E8%BC%89%E5%8F%8A%E4%B8%8D%E5%BE%97%E8%A8%98%E8%BC%89%E4%BA%8B%E9%A0%85 。
5. 現句：法源欄含「第68條（十日內填報保單資料）」。
   新句：從法源欄刪除第68條，正文沒用到。
   來源：旅行業管理規則第68條。
