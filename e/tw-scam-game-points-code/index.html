有人要你買遊戲點數、把序號拍照傳給他，就停止交易

證據 A 級收益量級未判定，依證據等級參考錢・不花錢・順手・要一點毅力

說人話

刑事警察局說，歹徒假冒業者打電話，說「工作人員操作錯誤」、「誤設會員等級」、「因駭客入侵導致資料外洩」，再假冒銀行客服，要求民眾操作 ATM、網銀匯款或購買遊戲點數來解除設定。刑事警察局說，業者客服不會主動來電。真正的帳務問題，不會要你買遊戲點數、把序號拍照傳給別人。

備註

第二篇頁面原本發布於 2023-04-20，早於 2023-10，只作背景；它說點數序號已交付他人時，可循流程鎖卡並向原購買店家申請退費，但該頁較舊。GASH 防詐鎖卡平臺是民間業者的機制，不是政府專線。同類手法見「接到自稱客服要你操作 ATM、網銀或買點數來「解除分期付款」，先掛斷再自己查證」、「收到繳費、包裹或點數到期的簡訊，不要點連結，自己開官方 App 或輸入官方網址查」、「接到可疑來電，先掛斷，再自己撥 165 或 110 求證」。
