身分證滅失或遺失，法律規定應申請補領（戶籍法第57條）。補領要本人親自辦理（第60條）。掛失可用網路24小時辦理（分自然人憑證、免自然人憑證兩種），也可以由本人持身分證明文件向戶政事務所臨櫃辦理；掛失後尋獲要辦撤銷掛失。補領要帶印章或簽名、戶口名簿正本或貼有相片的身分證明文件、最近2年內符合規格的相片（已建檔可免附），可到全國任一戶政事務所辦。被冒用身分使用身分證，法律有刑責（第75條）。

成本
錢 少：補領國民身分證每張新臺幣二百元（規費收費標準第3條）。時間：少，一次到戶政事務所，掛失可用網路辦理。毅力：些，要在遺失當天先掛失，再跑一趟補發。
收益
無法換算成金額，標「?」。補領本身花新臺幣二百元，避免的是身分證被拿去冒名申辦、被當成人頭。
過程成本
掛失不用錢，網路24小時可辦。補領要本人親自到戶政事務所，規費新臺幣二百元。信用報告每年度提供一份免費；查詢方法與其他免費條件見 tw-money-credit-report-check。申訴或訴訟等成本，本條不寫。
備註
掛失頁面說，遺失國民身分證的民眾自103年7月1日起可親自向任一戶政事務所申請補發；法條第61條的原則是向戶籍地戶政事務所，經中央主管機關公告者得向戶籍地以外辦理。身分證被冒用或變造，發現的機關會函知原發證機關註銷製發檔案資料（第62條）。非上班時間的電話掛失管道，其專線號碼不在本站白名單，本條不寫。戶政司兩個頁面的 HTML 沒有標日期，頁面更新日期取自 HTTP Last-Modified（305 頁 2026-03-27、388 頁 2024-11-14）。收益標「?」是因為可避免的冒用損失沒有官方數字。

A（法條與收費標準原文可直接對應；補辦流程為戶政司現行頁面）

同章：個人資料（9 條）

  • 向蒐集你個資的公司或機關，請求查詢、更正或刪除
  • 替網路銀行、Google、LINE 與社群帳號開啟兩步驟驗證，並定期檢查登入裝置
  • 手機遺失先更改重要帳號密碼並檢查登入裝置，平常就開好「尋找設備」
  • 問清蒐集目的再交身分證影本，只給必要資料並留意影本流向
  • 發現通訊軟體帳號被盜，先通知親友別匯款，再用平台「再次登入」功能取回
  • 遺失身分證當天先掛失、親自補領，並查一次信用報告防冒用
  • 把每個重要帳號設成不同密碼，並定期查看登入活動
  • 安裝 App 時只給與功能有關的個資，超額蒐集就拒絕
  • 收到個資外洩通知，先改掉重複使用的密碼並提防假客服來電
