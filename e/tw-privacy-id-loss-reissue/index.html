遺失身分證當天先掛失、親自補領，並查一次信用報告防冒用

證據 A 級收益量級未判定，依證據等級參考錢・花錢少・順手・要一點毅力

說人話

身分證滅失或遺失，法律規定應申請補領（戶籍法第57條）。補領要本人親自辦理（第60條）。掛失可用網路24小時辦理（分自然人憑證、免自然人憑證兩種），也可以由本人持身分證明文件向戶政事務所臨櫃辦理；掛失後尋獲要辦撤銷掛失。補領要帶印章或簽名、戶口名簿正本或貼有相片的身分證明文件、最近2年內符合規格的相片（已建檔可免附），可到全國任一戶政事務所辦。被冒用身分使用身分證，法律有刑責（第75條）。

收益

無法換算成金額，標「?」。補領本身花新臺幣二百元，避免的是身分證被拿去冒名申辦、被當成人頭。

過程成本
掛失不用錢，網路24小時可辦。補領要本人親自到戶政事務所，規費新臺幣二百元。信用報告每年度提供一份免費；查詢方法與其他免費條件見「每年免費查一次自己的聯徵信用報告，核對金融機構報送的資料」。

什麼情況要重查
上列條文或收費標準修正；補領規費調整（每年重驗）

成本

錢 少：補領國民身分證每張新臺幣二百元（規費收費標準第3條）。時間：少，一次到戶政事務所，掛失可用網路辦理。毅力：些，要在遺失當天先掛失，再跑一趟補發。

備註

掛失頁面說，遺失國民身分證的民眾自103年7月1日起可親自向任一戶政事務所申請補發；法條第61條的原則是向戶籍地戶政事務所，經中央主管機關公告者得向戶籍地以外辦理。身分證被冒用或變造，發現的機關會函知原發證機關註銷製發檔案資料（第62條）。戶政司兩個頁面的 HTML 沒有標日期，頁面更新日期取自 HTTP Last-Modified（305 頁 2026-03-27、388 頁 2024-11-14）。收益標「?」是因為可避免的冒用損失沒有官方數字。
